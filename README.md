## Featured Projects

### 🏫 Campus Network Design
Designed and simulated a multi-building campus network using Cisco Packet Tracer. Configured routers, managed layer-2 switching, applied structured IP addressing, and verified full end-to-end connectivity across all segments.

---

### 🏢 Small Office Network Design
Built a small office network integrating routers, switches, and VLANs. Configured inter-VLAN routing and validated network performance through systematic connectivity testing.

---

### 🔀 VLAN Configuration Lab
Implemented VLAN segmentation across multiple switches. Assigned switch ports to appropriate VLANs and configured trunk links to enforce logical separation and controlled inter-VLAN traffic.

---

### 🗺️ Static Routing Configuration
Set up static routes between multiple distinct networks. Verified reachability across all hops and documented route tables to confirm end-to-end packet delivery.

---

### ⚙️ Network Services Configuration
Deployed DHCP for automatic IP address allocation to client devices and configured DNS for hostname-to-address resolution — simulating a real ISP-style service layer.

---

### 🔍 Network Troubleshooting Lab
Systematically diagnosed and resolved network connectivity failures using Ping, Traceroute, and NSLookup. Identified misconfigured routes, incorrect subnet masks, and unreachable gateways through structured fault isolation.
